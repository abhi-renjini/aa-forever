PUBLIC WISHES SETUP — Ananthu & Abhirenjini

1. Go to https://console.firebase.google.com/ and create a Firebase project.
2. Add a Web app (</>) in Project settings > Your apps. Copy its firebaseConfig values into firebase-config.js.
3. In Build > Firestore Database, create a database. Choose a region and configure production rules.
4. In Firestore > Rules, paste the contents of firestore.rules and publish.
5. Host this entire website folder on Firebase Hosting, Netlify, GitHub Pages, or another HTTPS static host.
   Do not open index.html directly as file:// — ES modules require a web server.
   For local testing run `python -m http.server 8000` inside this folder and visit http://localhost:8000.
6. Test posting from one device and viewing from another.

IMPORTANT: This is a PUBLIC, unauthenticated guestbook. Anyone can read and post wishes.
It may attract spam or abusive posts. Firestore rules limit length but do not prevent spam.
For a public launch, consider Firebase App Check, moderation/approval workflow, and rate limiting.
Only the newest 100 wishes are displayed. No admin deletion UI is included; admins can delete from Firebase Console.
Firebase usage may incur charges depending on your plan and traffic.
